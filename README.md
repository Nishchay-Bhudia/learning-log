# learning-log

A public record of me learning how to work like an engineer rather than like someone who
just writes code that happens to run. Version control done properly, tests, planning work
before starting it, and documentation good enough that someone else can pick the project up.

There is no software in this repo. It holds the written work: a goal statement and the
planning board for the project I am using as the vehicle for all of it, a portfolio site
built with Next.js and TypeScript.

`Weekone_goal_statement.md` sets out what I want to learn and why. The short version is
that I can code small things, I have no idea how professional teams actually build
software, and I would rather learn the habits now than unlearn bad ones later.
