# Goal Statement
---

### Preferred Track  

The company track that interests me the most is the Google DeepMind track. I like the focus on research engineering because it combines math and coding to test new ideas. I am not choosing this track because I already know AI. I do not know how to build or train complex models yet. I am choosing it because I want to learn the engineering skills required to create reproducible experiments and demonstrate real data impact later on.  
---

### What I Want to Learn  

I want to move beyond writing basic code that only works on my laptop. I need to learn how to use version control properly so I can track my changes, use branches and also fix mistakes without creating a mess. I want to learn how to write automated tests to prove my code works before I share it. I also want to learn how to document my choices and write clear setup guides so someone else can understand my project quickly without me needing to explain it.  
---

### Why This Matters to Me  

Right now I am a student who knows how to code simple things, but I do not know how professional engineering teams build software. I want to develop strong habits early instead of learning the wrong way. Learning how to break big problems into small tasks and write reliable software will help me prepare for future opportunities. This syllabus is a way for me to show that I can be organized and create things that people can trust.
